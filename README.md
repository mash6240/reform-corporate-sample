# あおば住まい工房 — Sample Corporate Site

架空のリフォーム会社を想定した、5ページ構成のコーポレートサイトのコーディングサンプルです。
会社名・住所・電話番号・施工事例・価格などはすべて架空のものです。

## ページ構成

| ページ | 主な実装内容 |
|---|---|
| index.html（トップ） | メインビジュアルのスライダー、数字のカウントアップ、お知らせ一覧 |
| service.html（サービス） | ページ内リンク、左右交互レイアウト、ご依頼の流れ |
| works.html（施工事例） | カテゴリでの絞り込み（`?category=bath` のようにURLでも指定可能） |
| company.html（会社概要） | 代表メッセージ、会社情報テーブル、沿革のタイムライン |
| contact.html（お問い合わせ） | 入力 → 確認 → 完了 の3ステップフォーム、入力チェック |

## 使用技術

- HTML5（WAI-ARIA、パンくずリスト、`aria-current` によるナビゲーションの現在地表示）
- Sass（SCSS）… 設定・ベース・共通パーツ・ページごとにファイルを分割、BEM命名
- JavaScript（バニラJS、ライブラリ不使用）

## ヘッダー・フッターの共通化

静的サイトのため、`_src/` にある共通レイアウトとページ本文から、`build.py` で各HTMLを生成しています。
ヘッダーやフッターを変更するときは `_src/layout.html` だけを編集すれば、全ページに反映されます。

```bash
python3 build.py   # HTMLを生成
npx sass scss/style.scss css/style.css --style=expanded --no-source-map
```

## 備考

- 写真の代わりに、カテゴリごとのグラデーションとSVGアイコンを使用しています
- お問い合わせフォームは送信しません（実際のサイトでは PHP でメール送信を行う想定です）
